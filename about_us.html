About Us

Company Information

TravelBloom helps travellers discover dream destinations around the world. We recommend beaches, temples and cities based on what you search for, so planning your next trip is quick and inspiring.

  • Founded: 2026
  • Location: Kuching, Sarawak, Malaysia
  • Mission: To make travel planning simple, fun and personalised.

Guidance for Team Members

  1. Run git pull before starting work to get the latest code.
  2. Create a separate branch for each feature or fix.
  3. Write clear commit messages describing what you changed.
  4. Keep destination data in travel_recommendation_api.json up to date and accurate.
  5. Test the search (beach, temple, country) before pushing changes.
  6. Open a pull request and get one teammate's review before merging into main.
